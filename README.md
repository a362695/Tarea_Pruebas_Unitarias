
# Pruebas unitarias en Python

Proyecto para demostrar operaciones de archivos mediante Python y pruebas unitarias con unittest.

## Funciones

- Copiar un archivo.
- Eliminar un archivo.
- Detectar archivos inexistentes.

## Ejecutar las pruebas

python -m unittest -v

## Herramientas

- Python
- unittest
- Git
- GitHub
- Ubuntu Server
- VMware Workstation
